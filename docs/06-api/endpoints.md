# Endpoints

## Major handler surfaces

- `BudgetApi`: budget list, detail, save item, delete item, create budget, rename budget, categories, all budgets, resolve budget by date
- `CategoryApi`: category management
- `ItemNameApi`: item-name lookup and management
- `RecurringItemApi`: recurring-item list, save, delete, activate/deactivate, categories
- `Report`: report generation and export flows
- `UtilityApi`: shared utility endpoints if present
