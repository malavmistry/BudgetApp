# Documentation Health

## Purpose

Define how to keep the docs system aligned with the repository.

## Periodic checks

- Check for broken relative links.
- Check for conflicting rules between authoritative and dependent docs.
- Check for outdated architecture descriptions.
- Check for outdated project-structure rules.
- Check for missing documentation after repeated undocumented decisions.
- Check for duplicated standards.
- Check for overlapping or unclear agent ownership.
- Check that docs still match the codebase.

## Triggered checks

- Run a docs-health review after architecture changes.
- Run a docs-health review after adding a new cross-cutting rule.
- Run a docs-health review when reviewers find recurring confusion.
