# Agent Collaboration Protocol

Every agent handoff SHOULD use this structure:

## Task

## Context

## Relevant Files

## Decisions

## Constraints

## Work Completed

## Work Remaining

## Risks

## Validation

## Recommended Next Agent

## Rules

- Do not assume another agent remembers prior context.
- Include only the minimum facts needed for the next agent to act safely.
- Record important long-lived decisions in documentation rather than only in handoff text.
