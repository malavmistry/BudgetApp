# Architecture Decisions

This folder contains architecture decision records with meaningful long-term impact.

## When to add an ADR

- A new architectural pattern is introduced.
- A public contract or deployment model changes materially.
- A new project, layer, or shared abstraction is introduced.
- A data-ownership or security model changes.

## When not to add an ADR

- Local refactors
- Small implementation details
- Cosmetic code changes
