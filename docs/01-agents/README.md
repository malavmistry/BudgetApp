# Agent Catalog

This folder defines the specialized agents recognized by this documentation system.

## Usage rules

- Every agent MUST read `../99-meta/agent-rules.md`.
- Every agent MUST read its own file before acting.
- Agents MAY read additional domain documents listed in their required or optional context.
- Agents MUST follow the handoff format defined in `../99-meta/agent-collaboration-protocol.md`.

## Agent selection

Use `../99-meta/agent-decision-rules.md` to determine which agents must participate in a task.
