# Terminology

## Normative language

- MUST: mandatory requirement
- MUST NOT: prohibited behavior
- SHOULD: recommended default unless a documented reason exists
- SHOULD NOT: generally avoid unless justified
- MAY: optional behavior

## Project terms

- Use `budget item`, not `transaction record` in project documentation.
- Use `time-bound budget`, not `monthly envelope`, for budgets keyed by month and year.
- Use `linked budget` for additional inclusion through `BudgetItemLink`.
- Use `page handler` for Razor Page endpoint methods.
- Use `service layer` for classes in `BudgetApp/Services`.
