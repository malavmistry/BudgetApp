# Glossary

- `Primary budget`: the budget that owns a `BudgetItem` through `BudgetId`.
- `Linked budget`: a budget that includes an item through `BudgetItemLink`.
- `Time-bound budget`: a monthly budget identified by `IsTimeBound`, `Month`, and `Year`.
- `Envelope budget`: a custom named budget that is not month-bound.
- `Quick Add`: the home-page flow that saves a budget item by resolving the primary monthly budget from a transaction date.
- `Named handler`: a Razor Pages handler method such as `OnGetListAsync` or `OnPostSaveItemAsync`.
- `ADR`: architecture decision record.
- `Authoritative document`: the single file that owns a specific rule set.
