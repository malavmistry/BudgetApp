BudgetApp startup

Authoritative setup and migration instructions:
docs\09-development\development-workflow.md
docs\05-database\database-architecture.md

Native quick start (repository root):
1. Start the existing host SQL Server on TCP port 1433.
2. Set Database:Password in the ignored BudgetApp\appsettings.Local.json.
3. Run: dotnet run --project BudgetApp\BudgetApp.csproj

Docker quick start (repository root):
1. Start the existing host SQL Server on TCP port 1433.
2. Copy .env.example to .env and set DB_PASSWORD.
3. Validate: docker compose config --quiet
4. Start: docker compose up --build -d
5. Check: docker compose ps
6. Check migrations: docker compose logs budgetapp
7. Open: http://localhost:8080
8. Stop: docker compose down

Compose runs only the app, not SQL Server. Backups belong to the host server.
Before retiring the old Compose SQL Server, back up and transfer any volume data.
Startup creates a missing database or applies pending EF migrations to an existing one.
